# 银行柜面现金长短款复核与缴回系统

柜员结柜登记实盘现金 → 主管核对差额 → 财务确认全部未处理事项后关闭营业日。
长款进入待认领流程，短款办理缴回或填写责任说明；重复结柜、跨班交接、事后找到现金一律以调整记录留痕，跨日差额保留归属营业日。

## 一条命令启动

```bash
npm start
```

首次运行会自动完成：安装依赖 → 生成 Prisma Client → 创建 SQLite 库 → 播种演示数据 → 同时拉起前后端。

- 前端：http://localhost:5173 （盘点 / 复核 / 财务页面）
- 后端：http://localhost:3001/api （NestJS + Prisma + SQLite，库文件 `server/prisma/dev.db`）

演示用户（登录页点选即可）：

| 用户 | 角色 | 职责 |
|---|---|---|
| 张敏 / 李强 | 柜员 | 按面额登记实盘、点钞机清点、复盘修正、短款缴回、跨班交接 |

## 验证测试

```bash
npm test
```

7 个端到端用例（独立测试库，不影响开发数据），覆盖题目要求的三个验证点：

1. **金额核对**（`server/test/amounts.e2e-spec.ts`）
   - 机点与手点不一致 → 结柜单进入「待复盘」，不自动采信任何一方；主管须注明原因后才能确认以手工盘点为准；
   - 长款分次认领，未了余额与台账同步减少，调整记录前后余额快照衔接；
   - 短款缴回 + 财务回执入账；**同一回执号重复入账返回原结果，不再次冲销**；每一步台账全局配平。
2. **跨日差额**（`server/test/cross-day.e2e-spec.ts`）
   - 未复核结柜单 / 财务未确认事项存在时拒绝日结；确认后事项挂账结转；
   - 次日找到现金：调整记录落在次日（`postedDayId`），差额归属日（`attributionDayId`）保持原营业日不变；
   - 原结柜单与盘点明细原样保留，后续可查到原问题；调整前后账目一致。
3. **并发结柜**（`server/test/concurrency.e2e-spec.ts`）
   - 同一现金箱并发开启结柜只产生一张单（唯一约束 + 幂等返回）；
   - 两人同时结柜、同时复核同一单：只有一人成功（状态机守卫 409），差额只入账一次；
   - 同号财务回执并发到达：只冲销一次；
   - 柜员（含兼岗主管）复核本人结柜单 → 403。

## 关键设计

- **金额一律整数「分」**，面额盘点（应有/手点/机点三套数量）逐行留痕，差额 = 实盘 − 应有。
- **台账配平**：每笔入账是一组合计为 0 的分录（现金箱 / 长款待认领 / 短款应收 / 财务金库），与业务写入同事务提交；`/api/ledger/reconcile` 实时核对台账余额与未了事项。
- **调整记录只增不改**：重复结柜修正（含前后两套面额快照）、跨班交接、事后找现、认领、缴回、责任说明全部留痕，结柜页可展开原始记录。
- **幂等与并发**：结柜单 `(现金箱, 营业日)` 唯一；复核/日结用状态机条件更新（`updateMany ... where status`）；未了余额用乐观锁推进；财务回执以回执号为幂等键并在事务内占位创建，重复回执绝不重复冲销。
- **日结门禁**：存在待复核/待复盘结柜单，或存在财务未确认的未了事项时，营业日不可关闭；确认后未了事项挂账跨日结转并保留归属日。

## 目录结构

```
├── package.json            # npm start 一条命令（workspaces: server + web）
├── scripts/ensure-setup.mjs# 启动前自检：装依赖/建库/播种
├── server/                 # NestJS + Prisma + SQLite
│   ├── prisma/schema.prisma# 数据模型（结柜单/长短款/调整/回执/台账）
│   ├── prisma/seed.ts      # 演示数据（幂等）
│   ├── src/closings/       # 结柜：盘点/机点/提交/复盘/复核
│   ├── src/discrepancies/  # 长短款：认领/缴回/找现/责任说明/交接
│   ├── src/finance/        # 财务回执（幂等）+ 点钞机/财务接口本地模拟
│   ├── src/days/           # 营业日关闭/开立
│   ├── src/ledger/         # 台账与对账
│   └── test/               # e2e：金额核对 / 跨日差额 / 并发结柜
└── web/                    # React + Vite
    └── src/pages/          # 柜员结柜页 / 主管复核页 / 财务日结页
```
